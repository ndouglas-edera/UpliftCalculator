Methodology

How the estimate works

The model is intentionally directional. Customer-provided inputs drive the estimate; scenario multipliers show uncertainty rather than claiming a guaranteed outcome.

Expected opportunity$0
Engineering hours0

Engineering capacity

Recoverable operations and setup hours are calculated from the engineers supporting agent infrastructure, their stated maintenance percentage and workload setup. The result is capped at the team's total available annual hours.

Infrastructure efficiency

The model uses a bounded percentage of current agent infrastructure spend, with higher opportunity when repeated setup and parallel execution are more prevalent. The percentage is capped so the opportunity cannot exceed the modeled infrastructure spend.

Execution and state efficiency

Repeated initialization and branching create a bounded opportunity. This component is deliberately conservative until Edera has validated customer benchmark ranges.

Isolation / control

The model considers data sensitivity, infrastructure control requirements and current isolation spend. It does not assign a made-up security incident rate; incident economics are planned for a future revision.

Scenarios

Conservative = 65% of expected benefit; Expected = 100%; Aggressive = 130%. These scenarios represent uncertainty around the modeled opportunity, not a guaranteed financial outcome.
